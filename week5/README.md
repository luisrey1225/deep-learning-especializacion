# Week 5 – Clasificación multiclase con red neuronal densa

## Objetivo
Implementar una red neuronal para clasificación multiclase usando TensorFlow y Keras, y comparar configuraciones de entrenamiento mediante hiperparámetros.

## Qué se comparó
Se compararon dos modelos con la misma arquitectura, el mismo número de épocas y el mismo tamaño de lote. La diferencia fue la tasa de aprendizaje:

- Configuración 1: learning rate = 0.001
- Configuración 2: learning rate = 0.01

## Resultado principal
La comparación permitió observar cómo la tasa de aprendizaje afecta la estabilidad, la velocidad de convergencia y el desempeño final del modelo.

## Cómo ejecutar
Abrir el notebook en Google Colab y ejecutar todas las celdas en orden con la opción Run all.
